# QBZ191

给 **R.E.P.O.** 加一把可购买、可开枪的 **QBZ-191 步枪**。

- 一个 `.repobundle`（物品本体，走 **REPOLib** 的 Content 注册）
- 一个小插件 `.dll`（半自动扳机 + 开火黑球修复）
- 枪声已烘焙进 `.repobundle`（48kHz / 双声道）

交流：**#腾讯频道：pd77525911**

---

## 参数

| 项 | 值 |
|---|---|
| 类型 | Gun（出现在商店武器区）|
| 伤害 | 玩家 90 / 敌人 90 |
| 射速 | **半自动**，按一下打一发；冷却 0.28 秒 |
| 射程 | 25 |
| 后坐力 | 2.5 |
| 弹药 | 电池，满电 **30 发** |
| 价格 | 基础 12,500~15,000（商店按层数倍率 → 约 5 万~6 万）|
| 卡车 / 商店上限 | 各 2 把 |

---

## 功能

| 功能 | 说明 |
|---|---|
| **真半自动** | 插件在每次射击后复位扳机开关 → 一次按键 = 一发 |
| **枪声烘焙进模型** | 已打包进 `QBZ191.repobundle`，不加载外部音频，玩家无法替换 |
| **黑球修复** | 开火时那颗黑色小球是子弹模型材质丢失导致；现在子弹照常命中，但不再显示成黑球 |
| **自定义枪身 Shader** | 使用打进包内的自写 shader，不依赖游戏内置 shader（避免材质变紫红）|

## 安装

用模组管理器安装即可（依赖会自动带上）。手动安装时把内容放进 `BepInEx/plugins/cn_xc-QBZ191/`：

```
QBZ191.repobundle
QBZ191.dll
```
